Diálogo modal para confirmar acciones y para formularios cortos (nueva dirección, asignar repartidor, registrar reembolso).

**Úsalo** antes de toda acción destructiva o irreversible, y para formularios de hasta 5 campos que no merecen otra página.

**Lo que da el consumidor:** el título como pregunta o acción ("¿Cancelar el pedido FS-000124?", "Registrar reembolso"), el contenido y dos acciones: la de salida a la izquierda ("Volver"), la que actúa a la derecha con su verbo exacto.

**Reglas:** foco atrapado dentro y devuelto al botón que lo abrió; Esc cierra; en móvil ocupa el ancho con `espacio-4` de margen. En el backoffice es el `MatDialog` con estos tokens.

**No**: "Aceptar" / "Cancelar" genéricos; diálogos dentro de diálogos.

Galería del detalle de producto: miniaturas y foto principal del color elegido.

**Úsala** solo en el detalle (SPEC-2 P-2-02).

**Lo que da el consumidor:** las `imagenes` del producto y el `colorId` elegido; la galería muestra solo las de ese color (SPEC-2 C6). Al cambiar de color se reinicia en la principal de ese color.

**Reglas:** foto principal 4:5 de 1200px; miniaturas a la izquierda en escritorio y debajo en móvil, con la actual marcada en `fs-color-primario`; flechas del teclado para recorrer; texto alternativo = nombre + color.

**No**: mezclar fotos de distintos colores; ampliar con un visor que tape el precio en móvil.
